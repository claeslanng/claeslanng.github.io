Tune your 808 to the key

Find the song's key, find the 808's real note, and set that note as the root note in FL Studio. Then the piano roll plays in key, and you can fine-tune the last few cents.

Five steps

About five minutes per 808. You need the song's key, the 808's real note, and FL Studio's root note setting.

  1. Find the key of the song. Play the chords or the main loop into a key detector. PitchScope shows the key, its Camelot code, and how sure it is. Write it down, for example F minor.
  2. Find the real note of the 808. Play one long 808 note into a tuner set for bass. Read the steady part, not the first few milliseconds: many 808s slide down into their note. Don't trust the note in the file name; it's often wrong.
  3. Set the root note in FL Studio. Open the 808's Channel settings, right-click the key on its keyboard that matches the note you found, and set it as the root note. Remember that FL names octaves one higher: a tuner's F#1 is F#2 in FL. Now the piano roll plays the notes it shows.
  4. Fine-tune the cents. If the tuner shows the 808 a few cents sharp or flat, pull it in with the channel's fine pitch control. PitchScope turns green within 4 cents.
  5. Write the 808 on the right notes. Start on the root of the key, and use the fifth and the other scale notes below for movement.

When it still sounds wrong

The 808 sounds out of tune on some notes only

Low notes are close together: F1 and F#1 are only 2.6 Hz apart. A detuned sample can sound fine on one note and sour on the next. Tune it on the root, then check the highest and lowest notes of your 808 line.

The tuner jumps between octaves

Distortion adds strong harmonics, and many tuners lock onto those instead of the note itself. PitchScope's Bass mode is made for this, and doesn't jump an octave on distorted 808s.

It's in tune but fights the kick

Then it's probably phase, not pitch. See Kick and 808 phase, and tune the kick to the same note as the 808 or a fifth away.

Get the 808 in tune

PitchScope reads the note of an 808 down to 20 Hz, shows how many cents off it is, and finds the key of your loop. It's free, for Windows, made for FL Studio.
