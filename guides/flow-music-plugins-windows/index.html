Flow Music plugins on Windows

Google's own Flow plugins run on macOS only for now. To use a Flow Music plugin (.fmx) in FL Studio on Windows, load it in Flow FMX Host, a free VST3 that opens .fmx files.

What a Flow plugin is

Google Flow Music lets you describe an instrument or effect in plain words, build it in a Space, and since October 6, 2026 export it as a plugin for your DAW. The export is an .fmx file. On a Mac you drop it onto Google's Flow Instrument or Flow Effect plugin.

Google's plugins only run on macOS for now, and Google hasn't said when Windows is coming. The .fmx file itself isn't tied to the Mac, though, and that's where Flow FMX Host comes in.

Run it in FL Studio

Needs Windows 10 or 11 (64-bit) and the Microsoft Edge WebView2 Runtime, which almost every Windows PC already has. Takes a few minutes.

  1. Get an .fmx file. Build one in Flow Music: ask for an instrument or effect and use the word "plugin" or "VST", then download the build. Or start with one of the three free Flow plugins.
  2. Install Flow FMX Host. Download FlowFMX-Windows-x64.zip, unzip it, and copy both .vst3 folders into C:\Program Files\Common Files\VST3.
  3. Find it in FL Studio. Open Options, then Manage plugins, and click Find more plugins.
  4. Pick instrument or effect. Synths and samplers go in Flow FMX Instrument, in the Channel Rack. Effects go in Flow FMX Effect, in a mixer slot.
  5. Load the .fmx. Click Load Your Plugin and choose the file, or drag it onto the window. Its own interface opens, and every control shows up in FL Studio for automation.

Common questions

Does it sound the same as on a Mac?

Flow FMX Host runs the plugin's own sound engine and shows the interface it was designed with. Nothing is re-created or approximated.

The plugin window is blank

Install the Evergreen WebView2 Runtime from Microsoft, then reopen the plugin. The interface is drawn with WebView2.

What if I move the .fmx file?

Nothing breaks. The .fmx is saved inside your FL Studio project, so the project still opens if the file moves or you send the project to someone else.

Does it work in Ableton, Reaper or other DAWs?

Flow FMX Host is a standard VST3, made and tested for FL Studio. Other VST3 hosts on Windows may work, but they aren't tested yet. If you try one, tell me how it went.

Is it made by Google?

No. Flow FMX Host is free and open source, made by Claes Lanng Plugins, and isn't affiliated with or endorsed by Google.
